# 解析几何

## 直线

### 直线方程
- 一般式：$Ax + By + C = 0$
- 斜截式：$y = kx + b$
- 点斜式：$y - y_0 = k(x - x_0)$
- 两点式：$\frac{y - y_1}{y_2 - y_1} = \frac{x - x_1}{x_2 - x_1}$

### 斜率公式
过 $(x_1, y_1)$ 和 $(x_2, y_2)$ 的直线斜率：
$$k = \frac{y_2 - y_1}{x_2 - x_1}$$

### 直线位置关系
- 平行：$k_1 = k_2$ 且截距不等
- 垂直：$k_1 k_2 = -1$
- 夹角：$\tan\theta = \left|\frac{k_2 - k_1}{1 + k_1k_2}\right|$

### 点到直线距离
点 $(x_0, y_0)$ 到直线 $Ax + By + C = 0$：
$$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$$

## 圆

### 圆的标准方程
$$(x - a)^2 + (y - b)^2 = r^2$$

### 直线与圆的位置关系
圆心到直线距离 $d$，半径 $r$：
- $d < r$：相交
- $d = r$：相切
- $d > r$：相离

### 切线方程
过圆 $x^2 + y^2 = r^2$ 上一点 $(x_0, y_0)$ 的切线：
$$x_0x + y_0y = r^2$$

## 椭圆

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \quad (a > b > 0)$$

- 焦点：$F_1(-c, 0), F_2(c, 0)$，其中 $c^2 = a^2 - b^2$
- 离心率：$e = \frac{c}{a} < 1$
- 焦半径：$r = a \pm ex$

## 双曲线

$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$$

- 焦点：$F_1(-c, 0), F_2(c, 0)$，其中 $c^2 = a^2 + b^2$
- 离心率：$e = \frac{c}{a} > 1$
- 渐近线：$y = \pm\frac{b}{a}x$

## 抛物线

$$y^2 = 2px \quad (p > 0)$$

- 焦点：$F\left(\frac{p}{2}, 0\right)$
- 准线：$x = -\frac{p}{2}$
- 离心率：$e = 1$
