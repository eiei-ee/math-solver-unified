# 数学解题方法

## 分类方法

### 函数问题
1. 确定定义域（分母不为零、偶次根号非负、对数为正等）
2. 判断奇偶性：奇函数 $f(-x) = -f(x)$，偶函数 $f(-x) = f(x)$
3. 判断单调性：求导 $f'(x)$，判断正负
4. 求极值：$f'(x) = 0$ 找驻点，结合单调性判断
5. 求最值：比较区间端点值和极值点值

### 方程求解
1. 一元一次：移项合并 → $x = -\frac{b}{a}$
2. 一元二次：判别式 $\Delta$ → 求根公式/因式分解
3. 分式方程：去分母 → 解整式方程 → 验根（排除增根）
4. 无理方程：移项平方 → 解有理方程 → 验根
5. 指数/对数方程：利用单调性，化为代数方程

### 不等式求解
1. 一次不等式：移项（不等号方向不变）
2. 二次不等式：判别式 + 数轴穿根
3. 分式不等式：移项通分 → 分子分母分别求解 → 区间检验
4. 绝对值不等式：去绝对值 → 分类讨论

## 证明题方法

### 综合法
从已知条件出发，逐步推导得出结论。

### 分析法
从结论出发，找出使其成立的充分条件，逆向推导到已知条件。

### 反证法
假设结论不成立，推出矛盾，从而结论成立。

### 数学归纳法
1. 验证 $n=1$ 成立
2. 假设 $n=k$ 成立，证明 $n=k+1$ 成立
3. 由归纳原理得对一切 $n$ 成立

### 构造法
构造辅助函数、辅助几何图形、辅助数列等。

## 常见误区

1. **分母为零**：去分母后必须验根
2. **定义域**：对数真数为正、偶次根号下非负
3. **三角函数**：注意象限
4. **等比级数**：公比 $|q| < 1$ 方可求和
5. **均值不等式**：注意取等条件
6. **洛必达**：必须满足 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ 形式
