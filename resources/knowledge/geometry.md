# 平面几何

## 三角形

### 面积公式
- 底乘高之半：$S = \frac{1}{2}ah$
- 海伦公式：$S = \sqrt{p(p-a)(p-b)(p-c)}$，其中 $p = \frac{a+b+c}{2}$
- 两边夹角：$S = \frac{1}{2}ab\sin C$

### 正弦定理
$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$

### 余弦定理
$$a^2 = b^2 + c^2 - 2bc\cos A$$

### 勾股定理
直角三角形中：$a^2 + b^2 = c^2$（$c$ 为斜边）

### 射影定理
直角三角形中：
- $a^2 = c \cdot p$
- $b^2 = c \cdot q$
- $h^2 = p \cdot q$

## 圆

### 圆的标准方程
$$(x - a)^2 + (y - b)^2 = r^2$$

### 圆心角定理
圆心角等于它所对弧上的圆周角的 2 倍。

### 切线长定理
从圆外一点引圆的两条切线，切线长相等。

### 弦切角定理
弦切角等于它所夹弧所对的圆周角。

## 四边形

### 平行四边形
- 对边平行且相等，对角相等，对角线互相平分
- 面积：$S = ah$（底 × 高）= $ab\sin\theta$

### 矩形
- 四个角都是直角，对角线相等且互相平分
- 面积：$S = ab$

### 菱形
- 四条边相等，对角线互相垂直平分
- 面积：$S = \frac{1}{2}d_1d_2$（对角线乘积之半）

## 相似与全等

### 三角形全等判定
SSS、SAS、ASA、AAS、HL（直角三角形）

### 三角形相似判定
- 两角对应相等（AA）
- 两边成比例且夹角相等（SAS相似）
- 三边成比例（SSS相似）

### 相似性质
面积比 = 相似比的平方，体积比 = 相似比的立方
